# PatWatch - 0.1.0

A basic stopwatch that measures elapsed time in seconds.

## Requirements

- [ ] Display elapsed time in seconds.
- [ ] Start begins measuring elapsed time.
- [ ] While running, Stop pauses the measurement.
- [ ] When paused, Start changes to Continue.
- [ ] When paused, Stop changes to Reset.
- [ ] Continue resumes measuring from the paused time.
- [ ] Reset clears the elapsed time and returns the controls to their initial state.
